In `vite.config.js`, add `assetsInclude` so markdown files can be imported as raw text:

```javascript
import { defineConfig } from 'vite'

import tailwindcss from '@tailwindcss/vite'

  plugins: [react(), tailwindcss()],
  assetsInclude: [],
})
```

Also create a small Vite plugin inline to handle `.md?raw` imports — actually, Vite supports `?raw` imports natively, so no config change needed for that.

Instead, we need to configure Vite to allow glob imports of markdown files. No config change is actually needed — Vite's `import.meta.glob` with `{ query: '?raw', import: 'default' }` works out of the box.

### Task 4: Create Blog Post Loader Utility

**Files:**
- Create: `src/blog/loadPosts.js`

**Step 1: Create the post loader**

This module uses Vite's `import.meta.glob` to load all markdown files, parse frontmatter with `gray-matter`, and export sorted post data.

```javascript
import matter from 'gray-matter'

const postFiles = import.meta.glob('./posts/*.md', { query: '?raw', import: 'default', eager: true })

export function getAllPosts() {
  const posts = Object.entries(postFiles).map(([filepath, content]) => {
    const { data, content: body } = matter(content)
    return { ...data, body }
  })
  return posts.sort((a, b) => new Date(b.date) - new Date(a.date))
}

export function getPostBySlug(slug) {
  return getAllPosts().find(post => post.slug === slug) || null
}
```

### Task 7: Add React Router and Integrate Blog Routes

**Files:**
- Modify: `src/main.jsx`
- Modify: `src/App.jsx`

**Step 1: Wrap app in BrowserRouter and HelmetProvider in main.jsx**

```jsx
import { BrowserRouter } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <HelmetProvider>
      <BrowserRouter>
        <App />
      </BrowserRouter>
    </HelmetProvider>
  </StrictMode>
)
```

**Step 2: Add Routes in App.jsx**

Wrap the existing App content and blog pages in `<Routes>`:

```jsx
import { Routes, Route } from 'react-router-dom'
import BlogIndex from './blog/BlogIndex'
import BlogPost from './blog/BlogPost'

// In the component return:
<Routes>
  <Route path="/blog" element={<BlogIndex />} />
  <Route path="/blog/:slug" element={<BlogPost />} />
  <Route path="/*" element={/* existing map app JSX */} />
</Routes>
```

The existing map app JSX (everything currently returned) goes inside the `/*` route. This is the key integration point — the map app works exactly as before at `/`, and blog routes are separate pages.

### Task 9: Add Vercel Rewrites for SPA Routing

**Files:**
- Modify: `vercel.json`

**Step 1: Add SPA fallback rewrite**

Blog routes like `/blog/some-post` need to serve `index.html` so React Router can handle them. Add rewrites to `vercel.json`:

```json
{
  "rewrites": [
    { "source": "/blog/:path*", "destination": "/index.html" },
    { "source": "/((?!api|assets|.*\\..*).*)", "destination": "/index.html" }
  ],
  "crons": [{ "path": "/api/digest", "schedule": "0 14 * * 1" }]
}
```
